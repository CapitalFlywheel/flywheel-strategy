# FLYWHEEL STRATEGY visual concepts

Locked identity: `FLYWHEEL STRATEGY` / `$CAPITAL`.

All three concept boards were generated with the built-in image generator.
They explore an original identity informed by the official Strategy Q1 2025
media kit without copying its proprietary brandmark or B symbol.

## Route A - Institutional flywheel

Prompt direction: a premium Swiss-editorial identity using an original solid
five-blade flywheel, black background, `#FA660F` orange, warm white, tightly
set oversized grotesk typography, and a restrained orange-to-cream fade.

## Route B - Treasury machine

Prompt direction: a dark always-on capital loop using three nested orange arcs,
a black core, sparse ledger lines, and the exact mechanism line
`FEES -> MSTR -> HOLDERS`.

## Route C - Capital in motion

Prompt direction: a more energetic crypto-native poster system using six
angular capital blocks moving clockwise, huge cropped type, orange, black, and
warm white.

## Route D - Capital loop C

Prompt direction: a direct hybrid of Routes B and C. The hero mark is an
immediately readable `C` built from thick clockwise flywheel arcs and a sharp
forward cut. The banner combines a black technical field with an orange-to-
cream motion trail and the mechanism line `FEES -> MSTR -> HOLDERS`.

## Route E - Angular capital C

Prompt direction: six angular capital blocks form an open `C` around negative
space. The system uses the bold poster scale of Route C with the technical
information hierarchy of Route B.

## Route F - Signature C

Prompt direction: a heavy custom `C` with inward flywheel cuts, used alone as
the avatar and in a raised signature position beside the wordmark. The banner
uses black, orange, warm white, and a controlled lower fade.

## Route G - B-dominant hybrid

Prompt direction: keep Route B as the clear foundation (roughly 75%): black
technical field, nested orange flywheel, institutional treasury-machine tone,
and `FEES -> MSTR -> HOLDERS`. Add only Route C's angular motion trail and
bolder editorial energy as a secondary accent. No literal `C` monogram.

## Route H - C-dominant hybrid

Prompt direction: keep Route C as the clear foundation (roughly 75%): orange
avatar, angular six-part flywheel, warm-white poster field, and oversized
typography. Add Route B's black technical panel, routing lines, and disciplined
mechanism labels as secondary structure. No literal `C` monogram.

**Status: selected as the final visual direction.** The board is a concept
reference only; production avatar, banner, and website assets must be rebuilt
separately at exact target sizes and with clean typography.

## Shared constraints

- Exact public text: `FLYWHEEL STRATEGY` and `$CAPITAL`.
- No official Strategy wordmark or proprietary B symbol.
- No Bitcoin B, portraits, copied company logo, mascots, coins, or watermark.
- Avatar mark must remain legible at small mobile sizes.
- Banner content must survive responsive X cropping.
- Website and visual display copy must not end paragraphs with periods.
